# OFDE Nakshatra Round 2 — Complete Package

This package combines the two supplied ZIPs without overwriting or discarding either source.

Which folder should I use?

- Application/ — the newer OFDE_Nakshatra_Round2_Final.zip project. Extract the whole package, then open Application/OFDE/ in VS Code. Its README.md and start_ofde.ps1 are the main setup guide and launcher.
- Supporting_Materials/ — the earlier OFDE_Space_Debris_Complete_Team_Handoff.zip materials, including presentation decks, PDFs, playbook, and handoff notes. These are supporting/submission materials, not the runnable application code.

Important status note

The files are packaged together; this does not mean every environment-dependent test has passed. Follow Application/OFDE/README.md, then run the setup and verification instructions on Windows. Real SGP4/FastAPI integration and Windows end-to-end operation should be confirmed locally before claiming they are verified.
